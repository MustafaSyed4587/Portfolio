CHIP-8 Emulator

A working emulator of the 1970s CHIP-8 virtual computer, built from scratch in JavaScript. It runs three games and demos I wrote myself, and lets you watch the processor work: live registers and a running disassembly.

CHIP-8 is the classic first emulator project: 35 instructions, a 64 by 32 screen, and 4 KB of memory. You can load your own CHIP-8 programs (.ch8 files). Only load programs you own or that are free homebrew.

Rally: press 1 to move up and Q to move down (CHIP-8 keys 1 and 4). Return the ball to score. Missing ends the rally.

Processor

Last instructions

    The processor

    Sixteen 8-bit registers, a 16-bit index register, a stack, and two 60 Hz timers. Each step fetches two bytes, decodes the opcode, and runs it.

    The screen

    Sprites are drawn with XOR, so drawing the same sprite twice erases it. A pixel turned off sets a collision flag. Rally uses that flag to detect a hit on the paddle.

    My own programs

    I wrote a small assembler in Python and hand-coded each program, so every byte is mine. Nothing here comes from a commercial game.

    Keyboard layout: 1 2 3 4 / Q W E R / A S D F / Z X C V map to the CHIP-8 keypad 1 2 3 C / 4 5 6 D / 7 8 9 E / A 0 B F. Quirk settings change how a few instructions behave, because historical interpreters disagreed.
