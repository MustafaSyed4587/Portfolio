Project 10 · Systems programming

CHIP-8 Emulator

JavaScript · Emulation · Assembly · Systems programming

A working emulator of the classic CHIP-8 virtual computer, built from scratch in JavaScript and running games I wrote myself, with a live view of the processor.

  • Implemented the full instruction set: registers, stack, timers, XOR sprite drawing with collision detection, keypad input, and sound.
  • Wrote a small assembler in Python and hand-coded three programs, including a playable paddle game, so nothing depends on copyrighted ROMs.
  • Tested every instruction family with automated checks, then added a live register panel and disassembly so the processor can be watched working.

Play it

Load your own free CHIP-8 programs, or use the built-in ones. No commercial game files are included.

Project 11 · Game development

Undead Siege

JavaScript · Canvas 2D · Game logic · Web Audio

A top-down wave-survival shooter I built from scratch: board up the windows, earn points, buy weapons off the walls, and hold out as long as you can.

  • Built the game loop, collision detection, zombie behaviour (tear boards, climb in, chase), wave scaling and a points economy in plain JavaScript.
  • Generated every graphic and sound in code, with touch controls for phones, so there are no copyrighted assets.
  • Tested it with an automated bot that plays full games, then tuned difficulty until early waves were fair.

Project 12 · 3D game development

Undead Siege 2

JavaScript · three.js · 3D graphics · Web Audio

The sequel, rebuilt as a first-person 3D shooter: hold a house against waves of zombies, repair the windows, buy weapons off the walls, and survive.

  • Built a real 3D scene with lighting, fog, textures generated in code, and zombies modelled and animated from basic shapes.
  • Implemented first-person movement and mouse look, ray-cast shooting with headshot damage, collision and enemy pathing through windows.
  • Tested with an automated player that plays whole games, then tuned difficulty and fixed enemy behaviour bugs it exposed.
